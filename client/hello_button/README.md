# Gradus Hello button

A minimal reusable Flutter button module used to demonstrate the Gradus Client module layout.

## Public API

```dart
import 'package:gradus_hello_button/gradus_hello_button.dart';

const GradusHelloButton();
```

## Validate

```bash
cd client/hello_button
flutter analyze
flutter test
```

This package has no platform runner. The runnable Linux application remains in `client/app`.
