# Gradus design system

Browser-first visual studies for Gradus and the future home of reusable HTML
components. This component is independent of the Flutter client; a browser
prototype may be ported to Flutter later, but is not a Flutter package.

## Activity-detail prototype

Open `prototype/activity-detail.html` directly in a browser. It is a
phone-focused Modern Palaestra study with a grounded coach’s brief and
recent-self comparisons.

The prototype uses illustrative run data. Its pace, heart-rate, and elevation
controls update the chart; it does not parse FIT or GPX files.
